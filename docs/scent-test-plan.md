## 1. 현재 구조 (학습 결과)

**라우팅**
- `/test` → `LandingPage.tsx` — 스크린샷의 히어로 화면. 단일 컬럼, 중앙 정렬.

**사상체질 테스트 엔진**
- `SurveyPage.tsx`: `data/questions.ts`의 문항을 순서대로 노출, 보기 선택 시 4개 체질(태양·소양·태음·소음) 점수를 누적
- `LoadingPage.tsx`: 결과 계산 연출
- `ResultPage.tsx` + `data/results.ts`: 체질별 설명/키워드/추천 음료/생활 가이드, 레이더 게이지, 카카오 공유, 로그인 시 Supabase `quiz_results` 테이블 저장

**공통 리소스**
- Header 내비게이션: About / Wellness / Stories / **Test** (4개 고정, `Test`가 `/test`)
- Supabase 연동: `posts`(체질 스토리), `quiz_results`, `analytics` 등
- 스타일: 인라인 style 기반 + Tailwind 일부, `framer-motion`으로 애니메이션, `#0774C4`(블루)가 사상체질 테스트의 시그니처 컬러

즉 지금의 `/test`는 "사상체질 테스트 전용 단일 랜딩"이라, 향 테스트를 넣으려면 이 페이지 자체를 **테스트 허브(hub)** 구조로 바꿔야 합니다.

## 3. 확정된 방향: 생활 패턴 기반 향 건강 처방 테스트

취향(좋아하는 향 계열)이 아니라 **생활 패턴(수면·스트레스·피로·집중·실내환경)을 진단해서, 그 사람에게 부족한 부분을 과학적 근거가 있는 향으로 "처방"해주는 테스트**로 방향을 확정합니다.

- 사상체질 테스트와 마찬가지로 "문항 → 카테고리별 점수 누적 → 최다 득점 유형 판정 → 결과 카드" 구조를 그대로 재사용
- 차이점: 사상체질은 타고난 체질(불변)을 진단하지만, 향 테스트는 **최근 생활 패턴(가변적 상태)**을 진단 → "요즘 나에게 필요한 향"이라는 메시지로, 재방문/주기적 재검사 유도가 자연스러움
- 결과 화면에는 반드시 "아로마테라피는 보완적 웰니스 수단이며 질병의 진단·치료를 대체하지 않습니다" 등 디스클레이머 포함 (건강 관련 클레임이므로 과장 방지)

## 4. 향 건강 유형 체계 (5유형) — 과학적 근거 포함

각 유형은 생활 패턴 문항 점수로 판정되며, 추천 향은 실제 임상/대조 연구 근거를 기반으로 매핑했습니다.

### ① 이완형 — 스트레스·긴장 완화

- **생활 패턴 신호**: 업무 압박이 잦다, 사소한 일에도 짜증이 난다, 어깨·목이 자주 뻐근하다, 심장이 자주 두근거린다
- **추천 향**: 스위트오렌지, 라벤더, 일랑일랑, 베르가못
- **근거**: 아동 대상 오렌지 에센셜 오일 흡입 RCT에서 치과 치료 중 타액 코르티솔·맥박수가 유의하게 감소(Pediatric Dentistry, 2013). 고혈압 전단계/고혈압 환자 대상 라벤더·일랑일랑·베르가못 4주 흡입 RCT에서 혈압, 맥박, 주관적 스트레스, 혈청 코르티솔이 위약군 대비 유의하게 낮아짐(PMC3521421)
- **사용법**: 업무 중 데스크 디퓨저, 손목 롤온

### ② 숙면형 — 수면의 질 개선

- **생활 패턴 신호**: 잠들기까지 오래 걸린다, 자다가 자주 깬다, 자고 일어나도 개운하지 않다
- **추천 향**: 라벤더, 캐모마일
- **근거**: 만성심부전 환자 대상 8주 야간 라벤더 흡입 RCT에서 수면의 질이 전 시점에서 유의하게 개선(European Journal of Cardiovascular Nursing, 2023). 항암화학요법 환자 대상 라벤더·페퍼민트·대조군 비교 RCT에서 라벤더군의 수면점수가 유의하게 더 우수(PMC7132346). 뇌종양 수술 환자 대상 RCT에서도 총 수면시간·깊은 수면시간이 유의하게 증가(PMC12358394)
- **사용법**: 취침 30분 전 침실 디퓨저, 베개 스프레이

### ③ 활력형 — 피로·무기력 회복

- **생활 패턴 신호**: 오후만 되면 확 처진다, 아침에 일어나기 힘들다, 몸이 늘 무겁게 느껴진다
- **추천 향**: 로즈마리, 페퍼민트, 유칼립투스
- **근거**: 로즈마리의 1,8-시네올 성분이 각성·인지수행을 돕는다는 2024년 연구, 페퍼민트 흡입이 지속적 주의력과 반응속도를 향상시킨다는 대조 실험 결과 다수 보고
- **사용법**: 오전/오후 슬럼프 시간대 디퓨저, 휴대용 인헤일러 스틱

### ④ 몰입형 — 집중력 저하

- **생활 패턴 신호**: 멀티태스킹이 잦다, 한 가지 일에 집중하기 어렵다, 화면(모니터) 사용 시간이 길다
- **추천 향**: 페퍼민트, 로즈마리
- **근거**: 페퍼민트·일랑일랑 향의 인지수행·기분 조절 효과를 비교한 대조 연구에서 페퍼민트군이 지속주의 과제, 반응속도, 작업기억 점수에서 유의하게 우수(International Journal of Neuroscience, 2008)
- **사용법**: 책상 디퓨저, 롤온 (집중 필요 구간에만 짧게 사용)

### ⑤ 청정형 — 실내환경·호흡기 예민

- **생활 패턴 신호**: 환기를 자주 못한다, 미세먼지 많은 날 컨디션이 떨어진다, 콧막힘 등 가벼운 호흡기 불편이 잦다
- **추천 향**: 유칼립투스, 페퍼민트, 로즈마리 블렌드, 티트리
- **근거**: 유칼립투스·페퍼민트·오레가노·로즈마리 블렌드 스프레이를 활용한 RCT에서 사용 20분 후 상기도 감염 증상 심각도가 위약군 대비 유의하게 개선(Evidence-Based Complementary and Alternative Medicine)
- **사용법**: 실내 디퓨저, 환기 전후 룸 스프레이

> 참고: 로즈마리·페퍼민트가 ③④⑤에 걸쳐 등장하는데, 이는 실제 연구에서도 각성/인지/호흡기 완화 효과가 중첩 보고되기 때문입니다. 결과 화면에서는 유형별로 배합 비율·보조 향을 다르게 구성해 차별화할 수 있습니다.

## 6. 유형별 과학적 근거 상세 (텍스트 요약)

각 링크가 실제로 무엇을 보여주는 연구인지 요약합니다. 근거 수준은 유형마다 다르며, 특히 활력형·청정형은 숙면형·이완형만큼 대규모 RCT가 많지 않아 "효과가 보고된 바 있다" 수준으로 표현하는 것이 안전합니다.

**숙면형 (근거 수준: 높음 — RCT 다수)**
- 만성심부전 환자 80명 대상 8주 RCT: 매일 밤 8시간 라벤더 오일을 흡입한 그룹이 위약군보다 전체 관찰 기간 동안 수면의 질이 유의하게 더 개선됨.
- 두개내종양 수술 환자 대상 RCT: 수술 후 4일째, 라벤더 흡입군의 총 수면시간과 깊은 수면시간이 대조군보다 유의하게 길었음.
- 혈액암 화학요법 환자 100명 대상 단일맹검 RCT: 취침 전 20분씩 5일간 라벤더 오일을 도포한 그룹의 피로도와 수면의 질이 유의하게 개선됨.
- 암환자 120명 대상 라벤더·페퍼민트·대조군 3군 비교 RCT: 라벤더군의 수면 점수가 가장 우수했음(점수가 낮을수록 좋은 척도 기준).

**이완형 (근거 수준: 높음 — RCT 다수)**
- 6~9세 아동 30명 대상 치과 치료 중 오렌지 에센셜 오일 흡입 RCT: 흡입군의 타액 코르티솔 수치와 맥박수가 대조군보다 유의하게 감소.
- 고혈압전단계·고혈압 성인 52명 대상 라벤더·일랑일랑·베르가못 혼합오일 1일 1회 4주 흡입 RCT: 실험군의 혈압, 맥박, 주관적 스트레스 점수, 혈청 코르티솔이 위약군 대비 모두 유의하게 낮아짐.
- 일랑일랑 오일을 단독으로 흡입한 40명 대상 연구: 흡입 후 수축기 혈압이 유의하게 낮아지고 주관적 이완감이 증가.

**활력형 (근거 수준: 중간 — 소규모 연구·리뷰 위주)**
- 로즈마리의 주요 성분인 1,8-시네올이 각성과 인지수행에 관여한다는 2024년 연구: 로즈마리 향 노출이 알아채기 쉬운 각성 효과와 관련된다고 보고.
- 페퍼민트 향 노출 대조 실험 다수: 지속적 주의력 과제 수행, 반응속도, 주관적 각성도가 무향 대조군보다 향상됨. 다만 표본 규모가 작고 결과가 혼재된 연구도 있어 "확정적"이라기보다 "보고된 경향"으로 표현하는 것이 정확합니다.

**몰입형 (근거 수준: 중간 — 대조 실험 위주)**
- 페퍼민트·일랑일랑 향의 인지수행·기분 조절 효과를 비교한 대조 연구(International Journal of Neuroscience, 2008): 페퍼민트 노출군이 지속주의 과제, 반응속도, 작업기억 점수에서 대조군보다 유의하게 우수.
- 저농도 페퍼민트 향에 장기간(수 주) 노출시킨 연구: 단기 노출보다 주의력 향상 효과가 더 뚜렷하게 나타남.

**청정형 (근거 수준: 중간 — RCT 1건 + 통념)**
- 유칼립투스·페퍼민트·오레가노·로즈마리 블렌드 스프레이를 활용한 RCT: 스프레이 사용 20분 후 상기도 감염 증상의 심각도가 위약군보다 유의하게 개선됨.
- 주의: "면역력 강화"처럼 강한 의학적 클레임은 과장이 될 수 있어, 실제 카피는 "환기 후 쾌적함", "호흡이 편안해지는 향" 등 체감 표현으로 순화하는 것을 권장합니다.

**공통 주의사항**: 위 연구 대부분은 소규모(수십~수백 명) 임상/대조 연구이며, 흡입 방식·용량·환경이 실제 제품 사용과 다를 수 있습니다. 결과 화면에는 "아로마테라피는 보완적 웰니스 수단이며 질병의 진단·치료를 대체하지 않습니다"라는 디스클레이머를 반드시 포함해야 합니다.

## 7. 결과 화면 설계 방향

기존 `ResultPage.tsx` 패턴(유형 뱃지 + 키워드 + 레이더/게이지 + 추천 리스트 + 카카오 공유)을 재사용하되:

- 추천 리스트는 `results.ts`의 `drinks` 필드처럼 `scents: { name, note, evidence, usage }[]` 구조로 확장
- "근거 보기" 토글/아코디언으로 섹션 6의 연구 요약을 노출 → 신뢰도 강화
- 하단에 디스클레이머 고정 문구 삽입

## 8. 개발 재사용 전략

- `data/scentQuestions.ts`, `data/scentResults.ts` 신설 (구조는 `questions.ts`/`results.ts`와 동일한 인터페이스)
- 라우트 신설: `/scent-quiz` (설문), 결과는 `/scent-result` 또는 동일 페이지 내 스테이트 전환
- 장기적으로 `SurveyPage`/`ResultPage`를 `questions`/`results`/`테마컬러`를 props로 받는 제네릭 컴포넌트로 리팩터링하면 확장이 쉬움
- Supabase: `quiz_results`에 `test_type` 컬럼 추가 또는 `scent_quiz_results` 테이블 신설
